Folder sync now lives in the Leadership panel

To keep this control in one trusted place, connecting a report to a local folder — and re-syncing it — is done from the Leadership panel (bottom-left), not inside each report page. Open Leadership once, pick a folder for each report, and every future visit reads the latest files automatically.

Quick start guide
1

Open a report

Use the sidebar menu or the cards above to enter one of the three reports.

2

Connect a folder once

In the Leadership panel, point each report at the folder where its daily files are saved.

3

Sync anytime

One click on "Sync now" reads the newest files and rebuilds the report — no re-browsing.

4

Export as image

Grab a ready-to-share snapshot of any report with a single click.

Platform standards
✓Every report is an independent page with a unified design language (color, Vazirmatn/Inter font, spacing)
✓Persistent per-report folder access with one-click re-sync — no repeated file picking
✓Fully client-side processing — files are never uploaded to a server
✓Bilingual interface (English / Persian) with full RTL support
✓Accessible color contrast and visible keyboard focus
✓Standard PNG export for fast reporting to management
